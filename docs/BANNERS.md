# 배너 시스템

> 2026-09-26 · 구현: `src/components/AdSlots.tsx` · 데이터: `src/data/ads.json`

## 원칙

1. **배너는 끝에서 끝까지 늘리지 않는다.** 크리에이티브는 본문 폭(최대 1216px = `max-w-7xl` 1280 − 좌우 32px)에서 멈춘다. 1920·2560 모니터에서도 크기가 같고, 본문 목록과 좌우 선이 맞는다.
2. **화면 폭마다 비율을 바꾼다.** 한 장을 늘려서 자르지 않고, 폭별 이미지를 따로 받는다 (`<picture>`).
3. **글자는 이미지에 굽지 않는다** (자체 배너). 번역·접근성·잘림 문제를 피한다. 광고주 배너는 이미지 안 글자를 허용하되 안전 영역 안에만.
4. 광고는 항상 **SPONSORED / ADVERTISEMENT** 표시. SOS·긴급·공식 정보 카드 안에는 넣지 않는다.
5. 빈 광고 자리는 **렌더링하지 않는다** (빈 상자 금지). 단 광고가 있을 때는 크기를 미리 잡아 화면 밀림(CLS)을 막는다.

## 슬롯 목록

| 슬롯 | 위치 | 화면 폭 | 표시 크기 | 제작 파일 (2배) | 용도 |
|---|---|---|---|---|---|
| **Top bar** | 맨 위 한 줄 | 전체 | 높이 36px, 텍스트 | 이미지 없음 | 공지·스폰서 한 줄 |
| **Billboard** | 헤더 아래 | < 640 | **2:1** (예: 335×168) | **750×375** | 메인 스폰서 / 자체 배너 |
| | | 640–1023 | **3:1** (예: 689×230) | **1536×512** | |
| | | ≥ 1024 | **4:1**, 최대 1216×304 | **2432×608** | |
| **Leaderboard** | 목록 아래 | < 768 | **320×100** | 640×200 | 직접 광고 또는 애드센스 |
| | | ≥ 768 | **728×90** | 1456×180 | |
| **Event card** | 상단 가로 스크롤 | 전체 | 260–300px 카드, 텍스트 | 이미지 없음 | 행사·프로모션 |
| **Sponsor logo** | 페이지 하단 | 전체 | 칸 높이 80px | 로고 SVG/PNG | 후원사 |

Leaderboard는 IAB 표준 크기라 나중에 애드센스·프로그래매틱 광고를 같은 자리에 그대로 넣을 수 있다.

## Billboard 안전 영역 (광고주 전달용)

폭별 이미지 모두 동일한 규칙:

- 로고·글자·버튼은 **가운데 80% × 70%** 안에만 (모서리 20px 둥글게 잘림 + 오른쪽 위 SPONSORED 표시 자리)
- 오른쪽 위 **120×32px**(2배 기준 240×64)는 비워 둔다 — SPONSORED 표시
- 글자 최소 크기: 모바일 파일 기준 28px 이상 (표시 시 14px)
- 모바일(2:1)은 데스크톱(4:1)을 잘라 쓰지 말고 **따로 구성** — 4:1을 2:1로 자르면 양쪽 절반이 사라진다

## 데이터 형식 (`ads.json`)

```json
"hero": [{
  "id": "sponsor-2026-10",
  "url": "https://example.com",
  "alt": "Sponsor name — what the banner says",
  "image": {
    "mobile": "/banner/sponsor-mobile.webp",
    "tablet": "/banner/sponsor-tablet.webp",
    "desktop": "/banner/sponsor-desktop.webp"
  }
}],
"leaderboard": [{
  "id": "…", "url": "…", "alt": "…",
  "image": { "mobile": "/banner/…-320x100.webp", "desktop": "/banner/…-728x90.webp" }
}]
```

`hero`가 비어 있으면 자체 배너(Your link to Korea.)가 나온다. 자체 배너 문구는 `src/messages/*.json`의 `banner.*` 키.
